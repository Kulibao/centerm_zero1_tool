SATA 指示灯

开启：休眠硬盘绿色灯一亮一灭。关闭：休眠硬盘绿色常亮。读写闪烁、SMART 故障红灯和空槽提示不受影响。

蜂鸣器

开关控制开机时的提示音；测试按钮始终只响一声，不会关机。

内核与 GPU 修复

运行 Zero1 专用内核修复脚本，补齐设备树、initramfs 和 GPU 驱动加载配置。相较原版脚本，本版本新增：自动检查并刷新 GPU 模块索引；登记 Mali GPU 及 Rockchip 依赖模块；把驱动加入 initramfs 和开机自动加载列表；增加内核更新后自动恢复 GPU、设备树和启动链接的钩子。

执行期间可能影响启动配置，请确认没有其他维护任务；完成后请根据输出提示决定是否重启。

NPU 修复

使用前请先在飞牛应用商店安装“AI 引擎 (RK356X)”。本功能会启用 RK3568 NPU 设备树节点、登记 rknpu 驱动及依赖、配置开机自动加载，并自动创建内核更新后的恢复钩子。

修复完成后设备会自动重启，请提前保存所有正在编辑的文件，并确保执行期间不要断电。重启时网页连接中断属于正常现象。
